## Featured Projects

### AI-Powered Military Equipment Image Classification Platform

A full-stack computer vision platform that classifies uploaded images into five categories: Half Track, Helicopter, Jeep Car, Tank, and Warplane.

The project uses a PyTorch EfficientNet-B0 model with a React, Vite, and Tailwind CSS frontend and a FastAPI backend. It provides real-time predictions, confidence scores, probability distributions, prediction history, analytics, and model information.

> Developed as a graduation project for academic and research purposes.

### NovaLearn — Online Courses Platform

A responsive online courses platform built with HTML5, CSS3, and vanilla JavaScript. It includes course browsing and filtering, search, enrollment forms, dark and light modes, responsive layouts, mobile navigation, blog pages, FAQ pages, and contact forms.

[View NovaLearn on GitHub](https://github.com/Tariq-Zeyad/Online-Courses-Platform)

### Kotlin Logistics Management System

A collaborative Kotlin-based logistics management system for managing shipments, delivery operations, and inventory. The project is being developed by a team, with members contributing to different parts of the system throughout the development process.

Through this project, I am gaining practical experience in Kotlin programming, application development, software design, teamwork, and applying software engineering concepts to a real-world use case.
